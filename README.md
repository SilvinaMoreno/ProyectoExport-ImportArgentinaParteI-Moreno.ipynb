## 📌 Descripción del proyecto

Este proyecto analiza la evolución de las exportaciones e importaciones de la República Argentina
entre los años 2002 y 2025, utilizando datos mensuales oficiales.

El objetivo principal es:
- Explorar tendencias generales del comercio exterior
- Analizar variaciones temporales
- Visualizar patrones relevantes mediante gráficos
- Aplicar conceptos básicos de análisis de datos con Python

---

## 📊 Dataset

- **Fuente:** Datos oficiales de comercio exterior argentino  
- **Formato:** Excel (.xlsx)  
- **Periodo:** 2002 – 2025  
- **Frecuencia:** Mensual  

El dataset se encuentra en la carpeta `/data` del repositorio.
